# Rush Small

[![CI](https://github.com/rushlabs-ai/rush-small/actions/workflows/ci.yml/badge.svg?branch=main)](https://github.com/rushlabs-ai/rush-small/actions/workflows/ci.yml) [![License: Apache-2.0](https://img.shields.io/badge/license-Apache--2.0-blue)](https://github.com/rushlabs-ai/rush-small/blob/main/LICENSE)

**A small, cleanly licensed reranker you can reproduce with one command.** Rush Small v0 is
Qwen3-Reranker-0.6B, fine-tuned to match its 4B sibling (distillation) on Apache-2.0 data only,
with the whole recipe, every pinned revision and the evaluation in this repository.

Why bother? The strongest small rerankers today are either non-commercial (jina-reranker v3) or
trained on MS MARCO, whose licence is non-commercial too. Qwen3-Reranker-0.6B is Apache-2.0 and
good. This project asks an honest question: **how much of the 4B teacher's quality can a 0.6B
student recover from permissively licensed data alone?** Expect a small change either way. The
table below reports it as measured.

## Results

nDCG@10 on five BEIR test sets, reranking BM25's top 100 (`results/v0-eval.json`):

| Model | SciFact | NFCorpus | FiQA | ArguAna | SciDocs | Mean |
|---|---|---|---|---|---|---|
| BM25 | 0.662 | 0.306 | 0.233 | 0.484 | 0.154 | 0.368 |
| Qwen3-Reranker-0.6B | 0.746 | 0.354 | 0.367 | 0.660 | 0.205 | 0.467 |
| **Rush Small v0** | **0.741** | **0.350** | **0.397** | **0.643** | **0.199** | **0.466** |
| Qwen3-Reranker-4B (teacher) | 0.764 | 0.362 | – | – | – | – |

**v0 is a draw with the base model** (mean 0.466 vs 0.467). Training on GooAQ's question-and-answer
pairs helped question-style search (FiQA +3.0) and cost a little on argument retrieval (ArguAna
-1.7) and the science sets (-0.5 to -0.7). The teacher (4B) leads the 0.6B models by about 1-2
points where it was measured. Against the teacher on 300 held-out GooAQ queries, the student's
listwise KL fell from 0.356 to 0.155 and its top pick matched the teacher's
72% → 76% of the time: it learned the teacher on GooAQ, but that did not transfer
evenly to other domains.

Next for v1: a broader permissive data mix (argument, science and forum text, not only QA), more
hard negatives per query, and a lower learning rate or LoRA to keep the base model's breadth.

Training: 1,500 steps, 1 hour on one L40S. Full run, including teacher scoring and evaluation,
about $6 of Modal credit.

## Use

The weights are not published yet (v0 does not beat the base model, so a Hugging Face release
will come with v1). The recipe reproduces them. The model is a drop-in replacement for Qwen3-Reranker-0.6B: same prompt format, same yes/no
scoring. A GGUF build runs on llama.cpp and Ollama, and passes [rerankd](https://github.com/rushlabs-ai/rerankd)'s
`check` (it keeps the reranking head and prompt):

```sh
rerankd check rush-small-qwen3-reranker-0.6b-v0-q8_0.gguf
```

## How it was made

| Stage | What | Where |
|---|---|---|
| data | 12,000 GooAQ questions, each with the true answer plus 15 BM25 hard negatives from a 300,000-answer pool | CPU |
| teacher | Qwen3-Reranker-4B scores all 192,000 pairs (yes-minus-no logit) | 1 × L40S |
| train | full fine-tune of Qwen3-Reranker-0.6B, one epoch: listwise KL to the teacher's scores + 0.5 × pointwise BCE, lr 1e-5 | 1 × L40S |
| eval | nDCG@10 on five BEIR test sets, reranking BM25's top 100 | 1 × L40S per model |
| export | GGUF q8_0 with llama.cpp b11980 (pinned), then `rerankd check` | CPU |

```sh
modal run pipeline.py --stage all --smoke   # a few cents, end to end
modal run pipeline.py --stage all           # the real run
```

Every model and dataset is pinned to a commit in `pipeline.py`. The Python environment is
hash-locked (`requirements.txt`, nothing newer than 7 days at lock time). llama.cpp is pinned by
commit, and rerankd by release checksum.

| Item | Licence | Used for |
|---|---|---|
| [GooAQ](https://github.com/allenai/gooaq) (via sentence-transformers/gooaq) | Apache-2.0 | training questions and answers |
| Qwen3-Reranker-0.6B (student), Qwen3-Reranker-4B (teacher) | Apache-2.0 | base model, soft labels |
| BEIR SciFact, NFCorpus, FiQA, ArguAna, SCIDOCS | CC BY-SA 4.0 (BEIR copies) | evaluation only |

No MS MARCO, no data generated by a closed model.

## Limits

- One epoch, one seed, one learning rate: v0 is a reproducible baseline, not a tuned model.
- English-heavy training data. The base model's multilingual ability is not measured here.
- BEIR numbers depend on the BM25 first stage (bm25s, English stopwords). They are comparable within
  this table, not directly with other papers' tables.
